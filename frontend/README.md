# MediAI Care

AI Healthcare Platform (Frontend Only)
Create a premium, modern, production-quality healthcare web application called MediAI Care using React, Next.js, TypeScript, TailwindCSS, Shadcn UI, Framer Motion, GSAP, Recharts, and Lucide Icons.
This is a frontend-only project using realistic dummy data. No backend implementation is required.
